Which image formats are supported?

PNG

PNG is a lossless image format that supports transparency. It is useful for graphics, logos and images that need transparent backgrounds.

JPG or JPEG

JPG is commonly used for photographs and everyday images. It does not support transparent backgrounds.

WebP

WebP is a modern image format that supports lossy and lossless compression, and can help reduce image file sizes on websites.

Why convert image formats?

Different image formats are useful for different purposes. You may need JPG for broad compatibility, PNG for transparency or WebP for web images. Converting an image lets you choose a format that suits your needs.
