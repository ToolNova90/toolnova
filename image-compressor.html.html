How to compress an image

  1. Select a JPG, PNG or WebP image from your device.
  2. Choose the output format you want.
  3. Adjust the quality slider. Lower quality can produce a smaller JPG or WebP file.
  4. Select Compress image to create the new image.
  5. Preview the result and select the download button to save it.

Why use an image compressor?

Large image files can take longer to upload, share or load on a webpage. Compressing an image can reduce its file size and make it easier to store or share. The amount of compression depends on the image, its format and the quality setting.

Frequently asked questions

Is this image compressor free?

Yes. You can use this ToolNova image compressor for free in your browser.

Which image formats are supported?

You can select JPG, PNG and WebP images. You can choose JPG, PNG or WebP as the output format.

Are my images uploaded?

No. This page uses your browser to process the selected image. The image is not sent to a ToolNova server.

Why can a PNG file stay the same size or become larger?

PNG uses lossless compression. Depending on the image, converting to PNG may not reduce file size. Try JPG or WebP if you want a smaller file and can accept lossy compression.
