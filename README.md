# ToolNova — 15-tool starter project

A responsive, static website with 15 working browser-based tools. No API keys, database, login system, or backend are required.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For best results, use a local static server (for example VS Code Live Server).
3. PDF features load PDF libraries from CDN, so PDF tools need an internet connection. Image, text, and calculator tools run locally.

## Included tools
- Image: compressor, resizer, cropper, format converter, rotate & flip
- PDF: merger, page extractor, JPG to PDF, PDF to JPG
- Text: word/character counter, case converter, remove extra spaces
- Calculators: age, percentage, unit converter

## Deploy free
Upload the project files to a GitHub repository and connect the repository to Cloudflare Pages, or use Netlify Drop. Publish the contents of this folder as a static site.

## Before public launch
- Replace the placeholder contact email in `contact.html`.
- Review and customize `privacy.html` and `terms.html` for your actual business and services.
- Add original help content and clear instructions to each tool page/section as you expand.
- Test all tools on mobile and desktop with different file types and sizes.
- Add your own domain and connect Google Search Console.
- Apply for AdSense only after the site has useful, original content and complies with current program policies.
- Add affiliate links only after joining relevant programs; disclose affiliate relationships clearly.

## Important notes
- The site does not call AI services or external APIs.
- PDF libraries and fonts are fetched from public CDNs; these are third-party static assets, not API-key services. If you want fully offline hosting, download and self-host the library files and update the script paths.
- PDF-to-JPG exports each page separately. Browser download settings may ask permission for multiple downloads.
- This is a functional starter project, not a guarantee of AdSense approval, search ranking, or income.
