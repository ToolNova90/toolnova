How to resize an image

  1. Select a JPG, PNG or WebP image from your device.
  2. Enter the new width and height in pixels.
  3. Keep the aspect ratio option selected to preserve the image's original proportions. Turn it off to set width and height independently.
  4. Choose an output format and adjust quality for JPG or WebP if needed.
  5. Select Resize image, preview the result and download your resized image.

Why resize an image?

Resizing changes an image's pixel dimensions. A smaller image can be more suitable for a website, online form, document or social media post. Choosing dimensions that fit the intended use can also help avoid unnecessarily large images. Resizing is different from compression: resizing changes width and height, while compression focuses on reducing file size.

Image resizing tips

  • Keep the aspect ratio enabled when you want to avoid stretching or squashing the image.
  • Use the exact pixel dimensions requested by the website or platform where you plan to use the image.
  • Choose JPG or WebP when a smaller file is important and some quality loss is acceptable.
  • Choose PNG when you need a lossless output format.

Frequently asked questions

Is this image resizer free?

Yes. ToolNova's image resizer is free to use in your browser.

Which image formats are supported?

You can upload JPG, PNG and WebP images and choose JPG, PNG or WebP for the resized output.

Can I keep the original proportions?

Yes. Keep the aspect ratio option selected. When you change either dimension, the other dimension is adjusted to preserve the original proportions.

Are my images uploaded to a server?

No. The selected image is processed locally in your browser and is not sent to a ToolNova server.

Does resizing also compress an image?

Changing pixel dimensions can change the output file size, but resizing and compression are different operations. Use the Image Compressor page when your main goal is to reduce file size without choosing new dimensions.
